# Future work

The current release is intentionally guided and reversible. The following ideas are deferred until the quarantine and restore workflow has real operating history.

## Reasonable next improvements

- Select individual files inside a recommendation group.
- Remember organization preferences without remembering permission to remove files.
- Add a small native Mac interface over the same tested execution layer.
- Export a privacy-safe summary that omits filenames.
- Add content-aware organization only after a separate privacy review.

## Explicitly deferred

- Scheduled cleanup.
- Automatic quarantine or deletion.
- Unattended quarantine purge.
- Cloud backup or synchronization.
- AI access to file contents.

These are not blocked by interface work; they are deferred because they expand authority, privacy exposure, or permanent-deletion risk.
